\chapter*{摘要}\markboth{摘要}{摘要}

\par 本研究设计并实现基于物流领域大语言模型的智能运营分析助手，以对话式交互承接分析师的取数、异常定位与复盘需求。系统采用会话、规划、工具、知识四层架构，并在两个关键环节提出算法创新。面向请求分发，设计代价敏感分层路由与安全拒答机制，以代价矩阵加权 Focal Loss 与温度标定双阈值策略联合控制成本与风险。面向多步工具调用，设计不确定性感知规划与自修复框架，由规划器、验证器与有限状态机修复控制器协同提升链路可靠性。课题完成领域数据构造、模型微调、模块训练、系统集成与端到端评测，验证方法有效性与系统可用性。

\par \textbf{关键词：}物流运营；领域大语言模型；智能体；代价敏感路由；安全拒答；工具规划；自修复

\chapter*{Abstract}\markboth{Abstract}{Abstract}

\par This study designs and implements an intelligent operation analysis assistant built on a logistics domain large language model, serving analysts' daily data retrieval, anomaly investigation, and post-mortem analysis through conversational interaction. The system follows a four-layer architecture consisting of session, planning, tool, and knowledge layers. Two algorithmic innovations are proposed at key stages. A cost-sensitive hierarchical routing and safe-abstention mechanism jointly controls cost and risk via a cost-matrix-weighted Focal Loss together with temperature scaling and a dual-threshold policy. An uncertainty-aware tool planning and self-repair framework lets a planner, a verifier, and a finite-state-machine repair controller cooperate to improve end-to-end reliability. The project completes domain data construction, model fine-tuning, module training, system integration, and end-to-end evaluation, validating effectiveness and usability.

\par \textbf{Keywords:} Logistics Operations; Domain Large Language Model; Intelligent Agent; Cost-sensitive Routing; Safe Abstention; Tool Planning; Self-repair
